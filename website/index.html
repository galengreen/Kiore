Command line

The same command
on every computer.

Everything the Mac menu and the Omarchy bar do, you can do from a terminal. Handy on other Linux desktops, or for scripts and status bars.

On a Mac it's inside the app: /Applications/MouseTail.app/Contents/MacOS/mousetaild

Questions

Good to know.

How is it different from Universal Control or Deskflow?

Universal Control only joins Apple devices. Deskflow (and Synergy, Barrier and Input Leap before it) works across more systems, but one computer is the server whose mouse and keyboard you use. With MouseTail, whichever computer you're sitting at is in charge, pairing is encrypted out of the box, and sound and media keys come along too.

Why does macOS say it can't check the app?

MouseTail isn't notarised yet, which needs a paid Apple developer account. The first time, open System Settings → Privacy & Security and click Open Anyway. Every release is signed with the same certificate, so macOS keeps MouseTail's permissions when it updates.

Do my computers need to be on the same network?

Yes. They find each other with Bonjour (mDNS), so they need to be on the same local network, wired or Wi-Fi. If you run a firewall, allow mDNS and MouseTail's UDP port, 24802 by default.

The cursor's gone somewhere. How do I get it back?

It comes home by itself if the other computer locks, freezes or drops off the network. You can also press Ctrl Option Esc (Ctrl Alt Esc on a Linux keyboard) at any time, or run mousetail release.

Some keys come out wrong on the other computer.

Keys are sent by where they sit on the keyboard, not by the letter on them, so give both computers the same keyboard layout.

How do I uninstall it?

On a Mac, choose Quit MouseTail from its menu and drag it from Applications to the Bin; its settings live in ~/Library/Application Support/MouseTail. On Linux, run ~/.local/share/mousetail/uninstall.sh.

Something isn't working.

mousetail status shows what each computer can see. If that doesn't explain it, open an issue on GitHub and say which computers and desktops you're using.
